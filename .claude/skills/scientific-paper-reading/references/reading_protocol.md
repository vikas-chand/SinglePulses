# Reading protocol

## First pass

- What problem is being solved?
- Why does it matter?
- What does the paper claim is new?
- Which data or simulations support it?
- Which figure contains the argument?

## Methods pass

Record:

```text
sample selection
instrument/data products
preprocessing
background
model set
likelihood/statistic
component criterion
priors
simulations
robustness checks
```

## Results pass

Record measured versus assumed quantities separately.

## Critical pass

Ask:

```text
What was excluded and why?
What is conditional on a model?
Could another model produce the same observable?
Did time integration create the feature?
Are likelihood assumptions valid?
Are parameters identifiable?
Which result is visual but not quantified?
What source inconsistency exists?
```

## Project pass

Convert useful lessons into:

```text
code task
test
plot
catalog column
quality-control rule
new model
paper section
future project
```
