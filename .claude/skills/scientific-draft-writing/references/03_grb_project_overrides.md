# GRB project-specific writing overrides

## Preferred order

For manuscripts from the single-pulse project:

```text
observational result
statistical support
instrument/detectability caveat
physical interpretations
model-dependent derived quantities
falsification or next test
```

## Terminology

Use consistently:

```text
low-energy break
low-energy bump
blackbody-like component
photospheric component only after physical justification
forward shock (FS)
reverse shock (RS)
peak energy E_peak
break energy E_break
```

Do not use “thermal component” merely because a BB function was fitted; write “BB-like” or “candidate thermal” until alternatives are tested.

## Statistical statements

Do not write:

```text
proved by Delta AIC/BIC/C-stat
5 sigma from Wilks for a boundary component
no break because Band is preferred
```

Write:

```text
the model is preferred under the stated criterion
the component improvement was calibrated by simulations
a break remains allowed but unresolved
the data are non-identifying
```

## Physical inference

Every magnetization or Lorentz-factor statement must name:

```text
framework
launch-radius assumption
efficiency assumption
spectral decomposition
interval
```

## Tone

Preferred provisional tone:

```text
direct
critical but fair
specific
observations first
no inflated novelty claims
comfortable stating uncertainty
```
