# Writing Pattern Log — Li & Zhang (2021)

## Diagnostic with two physical payoffs

The introduction explains that detecting HLE gives both:

```text
an emission-radius constraint
and
a bulk-acceleration test
```

This makes the method feel physically consequential before technical details begin.

## Model ladder

The paper uses a strong progression:

```text
simple PL closure
-> candidate selection
-> time-dependent CPL test
-> radius and composition
```

Use this when a simple relation is only a screening approximation.

## Broad and conservative definitions

Phase I and Phase II show how the result changes under a stricter interpretation of the decay tail.

This is a reusable robustness-writing pattern:

> We first adopt a broad operational interval and then repeat the analysis using a conservative subset in which the target process is expected to dominate.

## Numbered method pipeline

The methodology states operational steps in the order they are executed and maps outputs to tables.

This is ideal for computational papers.

## Audit figure

Figure 1 simultaneously shows data, empirical pulse fit, human/model peak choices, and both fitted phases.

A good figure should expose subjective choices rather than hide them.

## Interpretation caution

The source sometimes moves from model tension to language such as “the only possibility.” Our writing helper should avoid that jump.

Preferred form:

> Within the assumptions of the constant-\(\Gamma\), single-component curvature model, the observed excess decay steepness favors bulk acceleration. Structured geometry, finite emission duration, or multiple components remain to be tested.

## Conclusion mirrors evidence

The conclusion follows the exact evidential chain:

```text
sample
phase definition
simple test
complex test
radius
physical interpretation
```

This is an excellent structure for our manuscripts.
