# Rhetorical moves bank

## Broad unknown -> physical stakes

Purpose: establish why a technical uncertainty changes the interpretation of a larger system.

Pattern:

```text
Although X is observed, its origin remains uncertain.
Resolving this ambiguity is necessary because it determines Y.
```

## Competing-model contrast

Purpose: show the live alternatives before introducing the chosen test.

Structure:

```text
Model A predicts...
Model B instead predicts...
A third class allows...
These alternatives differ observationally in...
```

## Capability before procedure

Purpose: explain why a dataset or method is worth using.

Pattern:

```text
Combining A and B extends the observable range..., allowing us to test...
We therefore...
```

## Observation timeline

Purpose: give the reader a coherent event before analysis details.

Order:

```text
trigger -> localization -> geometry -> notable photons -> duration -> follow-up -> redshift
```

## Base model -> added component -> alternatives

Purpose: make component selection auditable.

Order:

```text
fit base models
select/compare base continuum
add candidate component
quantify improvement
compare all base+component combinations
report shifts in continuum parameters
```

## Assumption bridge

Purpose: prevent a fit component from being silently equated with a physical object.

Pattern:

```text
In the following interpretation, we identify component X with physical process Y and assume Z. The derived quantities are conditional on these choices.
```

## Discussion by physical questions

Purpose: prevent the discussion from becoming an equation-by-equation recap.

Use subsection questions such as:

```text
Does the simplest model apply?
Which energy component dominates?
What mechanism is allowed at the inferred radius?
Which assumption controls the conclusion?
How does the source compare with analogous events?
```

## Comparison closure

Purpose: move from one case to a population-level motivation.

Pattern:

```text
Source A shares observables X and Y with sources B and C. Whether the same physical interpretation applies requires a uniform analysis of a larger sample.
```
