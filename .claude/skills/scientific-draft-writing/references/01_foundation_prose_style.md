# Foundation: scientific prose and style

## Clarity

- Put the main subject and verb early.
- Keep one principal claim per sentence.
- Introduce a symbol before using it.
- Keep comparison terms parallel.
- Replace vague referents such as “this” with the actual noun when ambiguity is possible.

## Logical paragraphs

A paragraph should have:

```text
claim or purpose
supporting evidence/reasoning
qualification or consequence
transition to the next unit
```

## Evidence calibration

Use:

```text
shows / measures                 direct result
supports / favors                comparative evidence
is consistent with               non-unique compatibility
suggests                          weaker inference
requires, under model X          conditional implication
remains possible                 not excluded
cannot distinguish               non-identifiability
```

## Economy

Remove:

```text
empty importance claims
repeated definitions
chronological narration with no argumentative role
lists of citations that do not distinguish viewpoints
multiple sentences saying the same result
```

## Precision

Always preserve:

```text
instrument
energy range
interval
statistic
uncertainty
reference frame
model assumptions
measured versus derived status
```

## Transitions

Prefer explicit logical transitions:

```text
However          contrast
Therefore        deduction
By contrast      alternative case
Because          cause
To test this     method motivated by question
Under this model conditional result
```

Do not overuse decorative transitions.
