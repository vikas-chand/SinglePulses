# Abstract helper

Use six moves:

```text
1. unresolved problem
2. data/sample
3. method
4. principal measured result
5. physical interpretation with condition
6. broader implication
```

Checklist:

- no unexplained acronym;
- no literature review;
- no result absent from the paper;
- measured and derived results distinguished;
- one main quantitative result included;
- conclusion does not exceed evidence.
