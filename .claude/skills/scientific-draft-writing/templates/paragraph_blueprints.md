# Paragraph blueprints

## Background–stakes–gap–action

1. State the unresolved problem.
2. Explain what larger physical quantity depends on it.
3. Name the competing explanations.
4. Identify the missing observation/test.
5. State what this work does.

## Model-comparison paragraph

1. State the baseline model.
2. State the added/alternative model.
3. Give the statistic and parameter count.
4. Report the comparison.
5. Report parameter shifts.
6. State whether the result is unique.

## Conditional-interpretation paragraph

1. State the adopted physical identification.
2. List the necessary assumptions.
3. Give the derived consequence.
4. State sensitivity to nuisance parameters.
5. Name the strongest alternative.

## Limitation–opportunity paragraph

1. State the limitation precisely.
2. Explain its direction of bias or missing capability.
3. Propose a discriminating test.
4. State what new result that test could enable.
