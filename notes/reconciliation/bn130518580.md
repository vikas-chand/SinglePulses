## LESSONS → skills files

- L10 (engine, HIGH): a railed BB at T_INT is not evidence of absence. If any resolved block in the burst has a VALID kT and the T_INT BB rails to the bound, the T_INT fit is broken. Fix: seed the T_INT BB from the flux-weighted mean of the valid resolved kT values, and emit an INTEGRATED_BB_RAILED diagnostic instead of silently letting VALID=False drop both BB models out of selection. bn130518580 T_INT railed at kT=1.000003 keV with kT=30 and 80 keV multistart seeds already in place, while its own blocks 6-16 give kT=30.7-50.3 with LRT up to 34.7.

- L11 (reporting, HIGH): astromodels' DoubleSmoothlyBrokenPowerlaw is symmetric under alpha1 <-> alpha2 (numerically verified), so DSBPL_ALPHA1/ALPHA2 come out in either order and DSBPL_XP is NOT the nuFnu peak. bn130518580 T_INT columns read (-2.09, -0.86, XP=2881) but the curve has low-energy index -0.86 and a nuFnu peak at 431 keV. Every DSBPL index, break and peak that reaches a table or figure must be derived by evaluating the fitted function; add EVAL_ALPHA_LO / EVAL_ALPHA_MID / EVAL_EPEAK columns to scripts/10.

- L12 (physics, HIGH): the DSBPL low break and the Band+BB blackbody are frequently ONE feature. Test it every time with xb vs 3.92 kT block-by-block. bn130518580: Pearson r=0.87 over 11 blocks, median xb/(3.92 kT)=1.13. When the correlation holds, report the degeneracy explicitly; never claim 'two-break, not thermal' or vice versa on AIC margin alone.

- L13 (integrated vs resolved): a component that COOLS and fades can be detectable in every resolved block and vanish (or rail) in the integrated fit, because one static component cannot track an evolving one. The reverse is also possible. Treat T_INT and the block sequence as separate claims and always report both; a T_INT winner is never a summary of the block winners.

- L14 (literature protocol): burst identifiers differ between papers. My ADS full-text probe for '130518A' in Burgess+2020 returned 0 and was WRONG - the paper indexes it as GBM trigger '130518580'. Always probe BOTH the GRB name and the bn/trigger name, and confirm a negative by grepping the actual PDF/HTML, never by an ADS full-text miss alone.

- L15 (literature protocol): when a dedicated paper and a catalog paper cover the same burst, diff against BOTH. Siddique+2022 (SBPL+BB, kT=34.25+/-1.50) and Dirirsa+2019 (plain Band, BB in menu but not required) disagree on the integrated blackbody using nearly the same window and instruments - agreeing with one is not verification, and the paper must flag the disagreement.

- L16 (frame): beta is an instrument-coverage variable, not a burst property. For bn130518580 every LAT/LLE-inclusive fit gives -2.55 to -2.78 and every GBM/Konus/Suzaku-only fit gives -1.97 to -2.27. Never diff beta across analyses with different high-energy coverage - and read the GCN residual notes ('hint of counts excess ... around ~10 MeV', GCN 14677) as evidence for extra structure rather than as noise.

- L17 (gate): _fit_is_physical enforces xb < xp for DSBPL but not monotonic softening (alpha_lo >= alpha_mid >= beta). Harmless for astromodels because the function symmetrises, but the gate should compute the ordering from the EVALUATED curve so the same code works if the model is ever swapped for an asymmetric implementation.
