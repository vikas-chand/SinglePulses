**BB+Band detection (Burgess-style model selection)** based on ΔBIC = BIC_Band − BIC_BBBand
across the 837 OK fits:

| Threshold | # bins | Interpretation |
|-----------|--------|----------------|
| ΔBIC < −6  | **620** (74%) | "positive" preference for BB+Band |
| ΔBIC < −10 | 126 (15%)     | "strong" preference for BB+Band |
| ΔBIC >  0  | 92 (11%)      | Band-only preferred |

The −6 / −10 thresholds correspond to the conventional Kass & Raftery (1995)
boundaries; whether to call these "BB detections" is a model-selection
decision pending Gor's sign-off (see GOR_REVIEW_STATUS.md).

## What's waiting on Gor

Read in detail in `GOR_REVIEW_STATUS.md`. In brief: there is no paper-draft
file in the project tree (no `.tex` anywhere), no `comments_from_gor.md`,
no `notes/` folder, and no email or message log of a prior review. The
working hypothesis is that this project is at the **"figures-and-numbers
ready, manuscript not started"** stage, and what is awaiting Gor is:

1. Sign-off on the **single-pulse threshold** (0.9983 from Busby & Lazzati,
   applied as-is).
2. Sign-off on the **BB-detection criterion** (ΔBIC threshold — currently
   nothing in the code records a per-bin "BB detected" boolean).
3. Sign-off on **parameter-tying / seed propagation** between adjacent BB
   bins (currently the previous-bin best-fit seeds the next bin; this is a
   judgment call and Burgess 2014 uses Bayesian priors instead).
4. Sign-off on which GRBs to **include in the published Ep–kT sample**
   (specifically: do GRBs with only Band-only successful bins, or with all
   parameters railed to bounds, stay or go?).
5. Decision on **how to present the 8 BAND_ONLY_OK / 2 FAILED cases** in
   the paper (footnote? appendix table? silent drop?).

These decisions all reduce to "what counts as a successful BB+Band
detection?" — see FAILED_FITS.md for the per-case diagnosis that should
inform Gor's answers.
