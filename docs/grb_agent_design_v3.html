Layer 0Boot — how the agent starts

The agent never starts by remembering; it starts by reading, through an agent whose only job is reading. The SKILL-READER consumes the operating docs, the position memory, and the burst queue, and returns a binding checklist: current burst and step, the step's skill, the ledger caveats that must ride with every number, and the parameter-scaling rules for this burst — the lesson that constants tuned to one pulse's width do not transfer. The DISPATCHER (NR-17) then turns the task into a roster: it classifies the artifact classes at stake, returns the required agents in gate order, and surfaces every register row whose trigger matches but whose guard is still PROPOSED — unguarded debt, named before work starts, so the session cannot silently rely on a guard that does not exist. Mode selection fixes the approver (PI, or an independent custom agent defined identically on Claude Code and agy — approval platform-independent, and never a producer). Boot's last act arms the hooks: un-gated .png figure delivery is blocked, not forbidden (the SendUserFile hook; the parallel catalog-write gate is designed but not yet armed) — the one enforcement layer that never failed in the discovery run. Boot also opens the machine-wide RAM arbiter (NR-12): every heavy job admits in gigabytes against measured peak RSS, never in cores — the 2026-08-17 shutdown (five product chains each reaching a 15 GB step, ~140 GB demanded of a 64 GB machine, 12.75 h of fits lost) is the failure that priced this in.

Layer 1The per-burst pipeline — one saved workflow per step

Every step is a saved workflow (deterministic, resumable, budgeted) with a fixed roster of custom agents whose system prompts are the contracts. The workflow's nature changes by step — that heterogeneity is the design:

  • Steps 0–1 · single producer + checks. No fan-out is earned; a numbers verifier confirms angles and catalog masks (whole-source sweep before declaring anything "not checkable").
  • Steps 2–4 · classify-and-act with a human organ. Recorded human selections are adopted, never re-adjudicated; in fully-AI mode a proposer drafts and the independent approver judges — the proposer holds no approval power (quarantine pattern).
  • Step 5 · deterministic with guards. Bayesian blocks + the S≥10 merge, with the ×√M bridge to combined-spectrum thresholds stated as method.
  • Step 7 · primitive-diverse verification. Every timing quantity is measured by estimators differing at the primitive (MVT three ways; lag by the validated DCCF tool with pulse-scaled windows; durations by windowed first-crossing with covariance-true MC). Estimator labels are part of the measurement; agreeing numbers from the same primitive count once.
  • Steps 6+8 · fan-out-and-synthesize with adversarial gates. The 24-model grid runs seeded and hard-guarded (live fit reproduces the stored solution to |ΔAIC| < 0.1 or the panel is refused-with-reason); band validity is code-gated (railed fraction, curve containment); montages composite only guard-passed panels; the per-bin notes reviewers then write the residual commentary that found the edge-blackbody census and the tie-hidden 30 MeV spread.
  • Step 9 · assembly + independent recompute. Report from products; paper via the ADS bibliography agent (hand-written BibTeX forbidden), the caption agent (CaptionHelper corpus voice), and a manuscript verifier that recomputes every printed number — it caught a transposed table on its first run.

The enforcement rail crosses everything, ordered by measured reliability: code guards → hooks → artifact self-caveats → fresh verifiers → external audit, with the distiller converting each incident into a lesson at the correct layer and a register row, same session.

The rail, stress-tested on itself (2026-08-18). The RAM arbiter — rail infrastructure, written and tested by its own producer — went through the gauntlet it enforces on science products. An external multi-agent cloud review found two real bugs and one broken invariant in it ("one burst in MVT at a time" was not actually enforced: uniquely-named lock tokens meant the mutex never contended). Then testing the fix found a deeper flaw the review's own reasoning had missed: zsh defers signal traps while a foreground child runs, and no trap runs at all under SIGKILL or a machine shutdown — the exact failure the guard exists to survive. Release is now self-healing (owner-PID reaping, verified by killing the process), and the episode is the strongest evidence yet for the design's central claim: none of it was caught by the failing agent itself (NR-13, NR-14, NR-15).

The approval loop. Every step's evidence lands in a per-burst live report the moment it exists; the PI (or the independent approver) stamps it there. Approval is machine-readable and can never be fabricated — a stamp without an approver identity is rejected, and test stamps are purged the session they are written. Feedback is the productive path: it must route to an enforcement layer before the session closes, and if the amended step had approved descendants, the cascade demotes them to STALE and clears exactly the build markers that must regenerate — accommodation is mechanical, not remembered.

Layer 2Campaign accumulators

Each burst deposits into state no single burst can see: the edge-gated blackbody census, the hard-tail phase pattern, the estimator-labeled MVT table, the lag–width table, the EAC rail census, and the failure-mode taxonomy. The accumulators are what the science layer consumes — and what makes 106 bursts more than 106 papers.

Layer 3Context — blind-first literature

Products freeze before published values are read. Then four context agents run: GCN intelligence; the ADS harvest with Scholar as the cross-community channel (every hit resolved to a bibcode before citing); the prior-art reader over the project family's own notes (we once re-derived a proof a sibling project had recorded two weeks earlier); and the P3 diff attributor, which classifies every ours-vs-published mismatch as frame, method, or band before the word "discrepancy" is permitted. Claims that survive pass LITVERIFY — adversarial citation verification in the pattern that once forced the retraction of two of our own criticisms.

Layer 4Science — interpretation last, three kinds of questions

The science layer runs last, by design: it consumes finished, gated results, accumulators, and verified context — never raw enthusiasm. A synthesis agent assembles the evidence table; three engines follow, each with a different epistemic posture; the summary answers three questions:

Q1 — Does this answer a gap in the field?

nature: registry matching + judge panel

Results are matched against a maintained gap registry populated by the context layer (the lag–MVT normalization no one has tested; the missing single-pulse-selected lag sample; the unbuilt GBM∩BAT MVT calibration set; the absent edge-gated blackbody census). A judge panel scores whether the evidence closes, narrows, or merely touches each gap — and says which.

Q2 — If a GRB assumption is violated, can this test it?

nature: adversarial pairs over an assumption registry

For each registered assumption (synchrotron line-of-death and cooling regime; single-shell curvature closure — slope one and its untested normalization; Band universality; photosphere ubiquity; estimator-independence of timing quantities), one agent argues our measurement constitutes a test and names the discriminating signature; a second tries to refute the test's validity — degeneracies, windowing, calibration. Only tests surviving refutation are reported; the rest are listed as not-yet-testable, with what would make them testable.

Q3 — Exploratory jumps: a spectrum of wild hypotheses

nature: generate-and-filter, forced diversity, graded S0→S3

Every entry carries a wildness grade and a falsifiable next measurement, and the whole section is quarantined as speculation (it feeds the idea bank; it enters no paper without promotion through Q1/Q2). Burst-1 gradient: S0 — the hard tail is a rise-and-tail phenomenon of one evolving zone. S1 — integrated composite components in catalogs are largely evolution artifacts, quantifiable across 106 bursts by the TINT-vs-bins comparator. S2 — published low-kT thermal rates are inflated by the same edge-artifact class our gate removes, and re-derivable. S3 — lag–width proportionality across the sample points to a geometry-dominated (curvature-only) origin for lags, testable against the Q2 curvature closure on the same data.

The closed loop. The science layer may suggest follow-up analyses — and in fully-AI mode, execute them: a surviving hypothesis compiles into a new workflow that re-enters the pipeline through the same gates. Suggestion is free; execution is gated; publication passes the PI. That is the whole agent: curiosity with a conscience.

Governance

Everything provisional-flagged until the campaign freeze; contracts amend only with the PI's quoted words; register rows land same-session; a PI catch is, by standing rule, a missing-agent debt — the design goal is to run them to zero. The register table stands at 33 rows (NR-1–NR-10 and NR-12–NR-23 — NR-11 retired to an operations audit — plus unnumbered rows), beside the 8-agent cross-cutting roster; four of these (NR-20…NR-23) were added the same day from an independent Codex ultra review that found real security and integrity defects in this very build; ten agent definitions exist as files, and every PROPOSED row is surfaced as unguarded debt by the dispatcher at task intake.
