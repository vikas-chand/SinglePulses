## ⚠ MEMBERSHIP FLAG — the GCN describes THREE peaks, our sample says "single"
GCN 36024, verbatim: *"The GBM light curve shows a **precursor, a main emission peak
and third weaker peak**, yielding a duration (T90) of about 35.6 s (50-300 keV)."*
Our `results/single_pulse_grbs.ecsv` row: `CLASSIFICATION = single`, `SCORE = 0.999444`,
`FAILURES = 1`.
**This is not adjudicated here.** The standing rule is that membership is decided by the
prominence-gated peak count against known single/multi controls, never by GCN wording
(the bn160625945 lesson) — so this flag is an INPUT to that test, not a verdict. What it
does establish is that the test must actually be run for this burst before any
single-pulse claim rides on it.

## ⚠ WINDOW FLAG — our analysis window excludes the catalog's early emission
- GBM catalog (`results/grb_sample.ecsv`): `T90 = 35.585 ± 0.81 s`, `T90_START = 3.648 s`
  → catalog burst interval ≈ **[3.6, 39.2] s**.
- Our approved source window (`results/background_intervals.ecsv`): **[18.0, 48.0] s**;
  the fitted blocks span **[22.27, 43.97] s**.
- Glowbug (GCN 36031) puts the **main peak onset at 2024-04-03 11:57:53.912 = T0+23.3 s**,
  duration 7.2 s, 31.9σ, and states it *"corresponds to the main emission peak seen in the
  GBM light curve"*.
So our window covers the MAIN peak and the later emission, and starts ~14 s AFTER the
catalog T90 begins — the precursor is outside it. That is a step-4 question (was the
precursor deliberately excluded?) and it also bears on the membership flag above: a window
that contains one peak will look single-pulsed whether or not the burst is.
