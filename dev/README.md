old plan. Kept for provenance; **not** user-facing documentation and not part of
the pipeline. The user-facing docs live at the repo root (`README.md`,
`BACKGROUND_SELECTION_PROCESS.md`, `KHUSHBOO_BACKGROUNDS.md`) and in `docs/`.

- `CODEX_AUDIT_REPORT_PIPELINE.md`, `..._PREPUB.md`, `CODEX_AUDIT_REPORT.md`,
  `..._R2.md`, `ANTIGRAVITY_AUDIT_REPORT.md` — independent code/science audits.
- `CODEX_AUDIT_REQUEST*.md` — the audit briefs used to produce them.
- `FAILED_FITS.md`, `FIX_PROGRESS.md`, `PRODUCTION_STATUS.md`,
  `STATE_2026-05-16.md`, `PLAN.md`, `GOR_REVIEW_STATUS.md` — historical status
  snapshots (point-in-time; may be stale).
