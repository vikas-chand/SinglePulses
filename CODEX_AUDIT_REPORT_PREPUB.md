# Pre-publication Audit Report

**Verdict: safe to push only with fixes.** The current index does not contain the 13 copyrighted root PDFs, secrets found by credential-pattern grep, non-whitelisted raw-data directories, non-whitelisted `clean_per_burst` outputs, `docs/_build/`, `plots/`, or detected editor artifacts; all six intended sample bursts are present and tracked in both whitelisted trees. However, the ignore policy still permits future secret/editor files, the new package/docs are not tracked at all, and the published methodology does not match the engine's selection behavior or the reported 91%/9% headline. Resolve the BLOCKER and HIGH findings before push. (`git ls-files`: 323 files, about 196 MB.)

## BLOCKER

1. **Secrets and common editor files are not ignored.** `.gitignore` covers Python/Jupyter/OS files and two tool directories, but `git check-ignore` confirms that `.env`, `.env.local`, `*.pem`, `*.key`, `.vscode/`, `.idea/`, `*.swp`, and `*.swo` are currently eligible for tracking. No live credential/private-key pattern was found by the required whole-tree grep, but the repository is not protected against accidental addition. **Citations:** `.gitignore:1`, `.gitignore:69`. **Fix:** add explicit environment, credential/key, and editor/backup patterns before staging; rerun `git check-ignore -v` and the credential grep.

## HIGH

1. **The packaging and documentation being audited would not be included in the push.** `pyproject.toml`, `requirements.txt`, `two_breaks/`, `docs/`, and `LICENSE` all return no entries from `git ls-files`; `.gitignore` itself is only a working-tree modification. **Citations:** `pyproject.toml:1`, `two_breaks/__init__.py:1`, `docs/api.rst:1`. **Fix:** after addressing this audit, intentionally stage the reviewed package, docs, license, and `.gitignore`, then inspect `git diff --cached --name-status` before pushing.

2. **`select_best()` does not implement its documented decision framework.** The docs say it applies Delta-AIC >= 10 and returns a winning model plus curvature class, but the function simply chooses the minimum physical AIC/BIC and returns model/LRT fields; it has no Delta-AIC threshold or curvature classification. Worse, when no fit passes the physical gate it falls back to the minimum unfiltered fit, contradicting the rule that railed or mis-ordered fits cannot win. **Citations:** `docs/api.rst:44`, `docs/pipeline.rst:97`, `scripts/10_spectral_fit_burst.py:539`, `scripts/10_spectral_fit_burst.py:557`, `scripts/10_spectral_fit_burst.py:571`. **Fix:** either implement the locked threshold/classification in `select_best()` and return `INCONCLUSIVE` when `phys` is empty, or narrow the API/methodology docs to state that thresholded classification is performed later by `scripts/31_draft_numbers.py`.

3. **The 91%/9% headline uses the wrong threshold for the declared locked framework.** README reports 91% thermal-or-degenerate versus 9% two-break while declaring Delta-AIC >= 10; `draft_numbers.json` shows 91%/9% for the Delta-AIC 6 split, but the Delta-AIC 10 split is about 87%/13% (94/108 versus 14/108). **Citations:** `README.md:17`, `README.md:131`, `results/draft_numbers.json:46`, `results/draft_numbers.json:53`. **Fix:** report 87%/13% for the locked Delta-AIC >= 10 framework, or explicitly label 91%/9% as the Delta-AIC 6 result and reconcile the methodological threshold everywhere.

4. **Documented clone-and-run workflows contain author-machine absolute paths.** The manifest command advertised in quickstart will read and write `/Users/salim/...` rather than the clone; the same defect affects scripts 31-35 and 37, while fitting scripts hard-code the author's Python/CALDB locations. **Citations:** `docs/installation.rst:37`, `docs/quickstart.rst:76`, `scripts/38_build_manifest.py:12`, `scripts/31_draft_numbers.py:18`, `scripts/29_refit_clean.py:17`, `scripts/10_spectral_fit_burst.py:48`. **Fix:** derive the repository root from `__file__`/`two_breaks.ROOT`, use `sys.executable`, and require or derive CALDB from `CONDA_PREFIX` instead of embedding user paths.
